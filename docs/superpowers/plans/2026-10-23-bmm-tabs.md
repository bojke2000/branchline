# BMM Tabs Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Work on independent maps in tabs without losing drafts, saved-file identity or recoverable work.

**Architecture:** A workspace owns stable sessions and transitions; each session owns its editor, drafts and viewport. One recovery coordinator publishes immutable snapshots and a workspace manifest under the existing exclusive lock. Extract ownership before adding tab widgets.

**Tech Stack:** Existing Rust/egui/serde/tempfile/fs2 stack; add `same-file` for opened-file identity, resolving and locking its compatible version during Task 4.

**Spec:** `docs/superpowers/specs/2026-10-23-bmm-tabs-design.md`

## Global Constraints

- Approved baseline is `c39b19c`; retain dark startup, root panning, Alt+Shift panning, type-to-replace, dragging and safe selection.
- Keep `.branchline`, bundle identity and application-data location; never alter Freeplane or REA.
- Keep 100,000 nodes, depth 256, 1 MiB fields, 64 MiB decoded text and 32 MiB file/snapshot limits.
- Enforce 256 MiB estimated workspace document/session storage, 32 MiB per history stack and 64 MiB shared history; no arbitrary tab-count limit.
- One application-data lock; no per-tab `RecoveryStore`.
- Mutations and callbacks target stable session IDs, never positions or the current active tab at completion time.
- Saved tabs reopen from fresh disk contents; normal quit remains Save/Discard/Cancel, not an implicit hot exit.
- Native IME/accessibility coverage remains unverified unless actually exercised with permission.
- No implementation until the user approves this plan and the execution method.
- Run commands from `/Users/macbook/examples/branchline` with `/Users/macbook/.cargo/bin` on PATH; do not install unrelated toolchains.

## Review Focus

- An externally replaced file must not remain falsely deduplicated by its previous inode: Task 4.
- Equal imported node IDs/revisions must not reuse another tab's cache or widget state: Task 2.
- A late failed quit must retain earlier discard candidates and all open tabs: Tasks 5–6.
- A recovery cleanup failure must retain its ownership/retry record across restart: Task 5.
- A capacity-blocked undo must retain its entry and drafts, not partially mutate state: Task 3.

`Workspace::new() -> Workspace`, `active_id() -> SessionId`,
`active() -> Result<&MapSession, WorkspaceError>`,
`session(id) -> Result<&MapSession, WorkspaceError>`
preserve an internal nonempty/valid-active invariant. A session can be a loaded
map or an explicit restore-error entry; error entries do not manufacture an Editor.
Use `SessionState::{Map(MapSession), RestoreError(RestoreFailure)}` for lookup
and return an explicit error when a map operation targets a restore-error entry.
Tab rendering uses `entry(id)` rather than assuming the active entry is a map.
Its signature is `Workspace::entry(id: SessionId) ->
Result<&SessionState, WorkspaceError>`.

`SessionId::new() -> SessionId` and
`MapSession::new_blank(id: SessionId) -> MapSession` construct new sessions.
`MapSession` owns its Editor, search state, viewport, explicit pristine blank
status and retained file identity. Editor owns inline and notes/link drafts;
`Editor::snapshot_with_drafts() -> Result<Document, EditorError>` validates
draft target IDs and document bounds. Recovery and exporters use this owner.

`Workspace::apply(id: SessionId, edit: EditorEdit) -> Result<(), WorkspaceError>`
is the UI's only editing mutation boundary. Define `EditorEdit` in
`src/app.rs` with Action(EditorAction), Key(EditorKey), Command(Command),
Select(NodeId), ToggleSelection(NodeId), BeginReplacement and
SetDraft { field: DraftField, text: String }. `DraftField` identifies inline,
notes or link buffers by node ID. UI widgets propose text updates instead of
writing unchecked growth directly into session strings.

`Editor::prepare(edit: &EditorEdit) -> Result<PreparedEdit, EditorError>` and
`Editor::commit_prepared(edit: PreparedEdit, stamp: u64)` separate admission
from publication. `PreparedEdit` is opaque and exposes the prospective session
estimate and new history cost; include intermediate draft commits where a
single action performs more than one existing history operation. Never clone
the entire retained history to implement rollback. Expose
`PreparedEdit::history_entries() -> usize`; reserve consecutive retention stamps
and pass the first to `commit_prepared`.
